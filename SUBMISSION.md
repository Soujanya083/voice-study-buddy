## Project description
Voice Study Buddy is an MCP server that turns Alexa+ into a study coach. Paste
notes and the Gemini API creates flashcards. Ask to be quizzed and it speaks one
question at a time, grades your answer, and reschedules cards with spaced
repetition. A weak-topics report shows where you need practice. Built by a
CSE student with a data analytics + generative AI background.
